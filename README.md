# Magic Monkey Scripts

[简体中文](README.zh-CN.md)

A collection of practical userscripts maintained in one repository. Each script has its own directory, documentation, version, and Greasy Fork release.

## Scripts

| Script | Description | Install |
| --- | --- | --- |
| [GitHub Copy Path & Line](scripts/github-copy-path-line/README.md) | Copy a selected file path and line range from a GitHub pull request diff. | [Install from GitHub](https://raw.githubusercontent.com/roxi3906/magic-monkey-scripts/main/scripts/github-copy-path-line/github-copy-path-line.user.js) |

## Installation

1. Install a userscript manager such as [Tampermonkey](https://www.tampermonkey.net/).
2. Open the install link for the script you want.
3. Review the requested permissions, then confirm the installation.

See each script's README for supported pages and usage instructions.

## Repository Layout

Every directory under `scripts/` is an independently versioned userscript. This keeps shared maintenance in one repository while allowing each script to be released separately.
